# Task Completion Report

ユーザ（ジュニアエンジニア）が変更内容を理解・判断可能とするために実行する。
タスク完了時の最終回答作成する。

## 基本ルール

- 形式は以下のテンプレートに準ずること。
  `.codex/skills/task-completion-report/template/template.md`
- 日本語で記載する。
- Markdown形式で記載する。
- 実際に実施した内容だけを書く。
- 実行していないコマンドやテストを実行したように書かない。
- 内容がない項目も省略しない。
- 該当しない場合は「なし」と記載する。
- 検証を実施できなかった場合は「未実施」と理由を記載する。
- 判断記録には、ユーザーが判断を理解するために必要な要点のみ記載する。
- 詳細な内部思考ではなく、判断、根拠、代替案、採用理由を簡潔にまとめる。

## 最終回答ファイル出力先

以下のフォルダに最終回答ファイルを格納する。
ファイル名は修正内容を表す名称とする。
`docs/task-completion-report/`
